Prefix

C-a C-otab tree, searchable
C-a wsame tree
C-a ssame tree, windows only
C-a b / ltoggle to the last tab
C-a pprevious tab in order
C-a nnext tab in order
C-a 1-9jump to tab
C-a mjump to a call
C-a cnew tab
C-a xclose tab
C-a vtoggle vim mode
C-a ,settings
C-a ?this help
C-a C-amove caret to line start

Vim mode

h j k lscroll
d / uhalf page down / up
gg / Gtop / bottom
f / Flink hints, F opens in a new tab
/ n Nfind, next, previous
H / Lback / forward
rreload
Escleave vim mode
