Tmuxium

Settings are stored in your Chrome profile and follow you between machines.

Prefix

Click the box and press the combination you want. It needs at least one of Ctrl, Alt or Cmd. Left alone it follows each machine, so leave it alone unless you want the same key everywhere.

Keys

Press a key for each action. Modifiers are ignored after the prefix, so Ctrl-X and x are the same key. ? and 1-9 are fixed.

Search engine

Used by the new tab page. Pick one, or choose Custom and write a URL with %s where the query goes.

Sites to stay out of

One host per line. mail.google.com matches that host, *.google.com matches the domain and everything under it. On these sites no key is intercepted at all. Paste a full URL if it is easier, it gets reduced to the host when you save. The list starts with documents, spreadsheets and mail, where the browser's own editing keys matter more. Delete any line you disagree with.
